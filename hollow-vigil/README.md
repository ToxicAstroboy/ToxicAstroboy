# HOLLOW VIGIL

*A mountain village. A missing research team. A bell that never stops ringing.*

A low-poly, PS1-style survival horror game in the spirit of Resident Evil 4. The camera sits over your shoulder, you can't move while aiming, you kick staggered enemies, a village siege holds you until the bell rings, there's a travelling merchant, and there's a two-phase boss. Play time is about 30–45 minutes, and the loop structure is built to make you play again.

Models are generated by a **Blender** Python script. The game runs in **Godot 4.3+**.

---

## Quick start (play in 2 minutes)

1. Install **Godot 4.3** or newer (the standard build; you don't need .NET): https://godotengine.org/download
2. Open Godot, click **Import**, and select `hollow-vigil/game/project.godot`.
3. Press **F5** to play.

The game runs without any extra step: if the Blender models haven't been generated, it builds matching low-poly stand-ins at runtime.

## Build the 3D models with Blender

```bash
blender --background --python hollow-vigil/blender/build_assets.py
```

You can also open Blender, go to **Scripting**, open `blender/build_assets.py`, and click **Run Script**.

The script writes 25 `.glb` models (8 characters and 17 props) into `game/assets/models/`. Open the Godot project once so it imports them; after that the game uses them automatically. Imported materials are converted to the game's PS1 shader, so the art style stays consistent.

Characters are built from separate parts whose origins sit at the joints (`Torso`, `Head`, `ArmL/R`, `LegL/R`, `Tent1-4`, `Eye`, `Eyes`). The game animates these joints in code, so you can reshape any model in Blender and re-export it, as long as the part names and pivots stay the same.

## Controls

| Key | Action |
|---|---|
| WASD / Mouse | Move / look |
| Shift | Run |
| Right mouse | Aim (you **cannot walk while aiming**) |
| Left mouse | Fire (while aiming) |
| R | Reload |
| F | Knife (also breaks crates and barrels) |
| E | Interact / **KICK** a staggered enemy / finisher |
| Q | Quick 180° turn |
| 1 / 2 / 3 | Handgun / Shotgun / Magnum |
| H | Use herb or spray |
| L | Flashlight |
| Esc / Tab | Pause and inventory |

**Tip:** head and leg shots make enemies stagger. Step in and press **E** to kick, which hits everyone around you.

## Chapters

1. **The Road**: a broken-down car, a woodcutter who doesn't flinch.
2. **Grauwald**: villagers kneel around a burning stake. Then they all look up at once. Survive the siege until the bell tolls.
3. **The Butcher's Yard**: a merchant in a blue-lit shed, and a sack-headed brute who charges (make him hit a wall).
4. **Still Water**: a research camp, a cemetery, a mausoleum riddle, and a grave with your name on it. Stay away from the lake.
5. **The Chapel of the Choir**: meet Father Aldric and solve the hymn of the three bells.
6. **The Vigil Below**: the crypt, Dr. Hart in a cage, and a skeleton holding a revolver engraved *E.R.*
7. **The Father**: a two-phase boss: the priest first, then *The Choir*.

## Project layout

```
hollow-vigil/
├── blender/build_assets.py   # Blender: generates all characters and props (.glb)
├── tools/gen_audio.py        # synthesises every sound effect and music loop (pure Python)
└── game/                     # Godot 4 project
    ├── main.tscn / scripts/main.gd   # flow, render pipeline, cutscenes, endings, autotest
    ├── scripts/world.gd              # level layout and every scripted event
    ├── scripts/player.gd, enemy.gd, boss.gd, body.gd (procedural animation)
    ├── scripts/ui.gd, story.gd (all documents, including loop variants)
    ├── shaders/psx.gdshader          # vertex snapping + nearest-filtered textures
    └── assets/sounds/*.wav           # generated audio
```
